Alamo is a lightweight cross-platform C++ arcade framework designed for building retro pixel-art games.

It provides a simple game container architecture where multiple games can run inside the same engine.

Target platforms include:

- Linux
- macOS
- Android

Planned features include:

- joystick/gamepad support
- touch controls
- retro pixel-art rendering
- simple game loop architecture
- multiple games running inside the same engine

Alamo is designed as a personal arcade platform where different games can be developed and run using the same underlying engine.
